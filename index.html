how it works

Play retro arcade games online with friends

Retro P2P is a free browser-based multiplayer arcade emulator for the hardware of the early nineties — Capcom's CPS-1 and CPS-2 and SNK's Neo Geo, the boards behind the golden age of fighting games, beat 'em ups and run-and-guns. A room holds up to three players with voice chat built in; there is nothing to install, no account to make and no game server in the middle.

  1. Start a room

    One click, pick a name, and you get a room code and an invite link to hand your friends.

  2. Friends join in their browser

    They open the link on their own machine. Only the host loads a game — everyone else is sent the host's copy inside the room.

  3. Everyone plays the same frame

    Each browser runs its own emulator in deterministic lockstep — P2P netplay where only controller inputs cross the wire.

          Questions

          before you press start
          What is this?

          90s arcade classics, played together in your browser. Up to three players, perfectly in sync. Nothing to install, no accounts, no servers.

          How do I play with friends?

          Press Start a room and share the code or link. Friends pick a name and join — you load the game, and everyone starts at once.

          Which games can it play?

          Games for Capcom's CPS-1 and CPS-2 and SNK's Neo Geo — the era of fighting games, beat 'em ups and run-and-guns.

          Where do the games come from?

          From you. This player ships no games and downloads none — the host loads a ROM zip, and how you obtain one is up to you. Keep its original filename.

          Do my friends need the game file too?

          No. Only the host loads a file — everyone else receives it automatically in the room.

          My Neo Geo game will not start.

          Neo Geo games need the neogeo.zip BIOS. Pick it together with the game. Capcom games need no BIOS.

          Why does it ask for my microphone?

          Voice chat. You join muted — press M to talk. While muted, no microphone is open at all. Saying no is fine: you will still hear the others.

          Do I need a controller?

          No — the keyboard works out of the box. A gamepad is picked up automatically; open Controls to test and calibrate it.

          No games ship with this and none are fetched for you — bring files you are entitled to use.
